# Egern-Rule-Set

自用 Egern 规则集，每天自动从最初上游同步并转换，不依赖任何中间仓库。

## 运作方式

每天北京时间早上 10 点（UTC 02:00），GitHub Actions 自动运行 `.github/workflows/sync-rules.yml`，全程无人值守：

1. **拉取上游**：下载各上游最新规则文件
2. **转换格式**：`scripts/convert.py` 将 Surge `.list`、Loon `.lsr`、DOMAIN-SET 等格式统一转成 Egern 原生 YAML，排序去重
3. **合并多上游**：同一规则集若有多个来源，先合并去重再转换
4. **自动提交**：有变化即提交到 main 分支，无变化则不做任何改动
